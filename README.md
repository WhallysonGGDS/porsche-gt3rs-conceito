# 911 GT3 RS — conceito de portfólio

Site conceitual e cinematográfico: o 911 GT3 RS contado como um filme, quadro a quadro, controlado pelo scroll.

- 240 quadros em canvas (desktop 1280px / mobile 860px), carregados em camadas
- GSAP + ScrollTrigger, Lenis para scroll suave
- Fonte Archivo variável (eixo de largura) servida localmente
- HTML estático, sem build — compatível com Vercel

**Projeto não oficial.** Sem vínculo com a Porsche AG. Vídeo de origem gerado por IA.
Direção e código: Whallyson Gabriel.
